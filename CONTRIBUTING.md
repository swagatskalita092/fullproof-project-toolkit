# Contributing

This repo is a living methodology, not a finished artifact - contributions are genuinely welcome.

## Useful contributions

- **A new idea for `docs/08_idea_bank.md`**, stated the way the rest of the list is: by its invariant, with a note on what it proves beyond the shallow version.
- **A new worked example for `examples/`**, drawn from a real project you actually built and verified - not a hypothetical. Follow the honesty rules in `skill/honest-documentation/SKILL.md`: real bugs included, no fabricated numbers.
- **A fix or clarification to any `docs/` file** - if a step was confusing to actually follow, that's a real bug in the methodology itself.
- **A new focused skill**, if there's a genuinely distinct step this pipeline is missing - open an issue first to discuss the scope before writing it, so it doesn't duplicate an existing one.

## What doesn't fit here

Generic "best practices" advice not grounded in something actually built and verified. The whole point of this repo is that everything in it is real, not aggregated opinion.

## How

Open an issue first for anything beyond a small fix (a typo, a broken link) - for bigger additions, it's worth agreeing on scope before writing the content. Otherwise, a pull request is fine.
